# Coffee Shop Sales Analysis

An end-to-end Data Analytics portfolio project using SQL and Microsoft Excel to explore coffee shop sales performance and generate meaningful business insights.

## Project Overview

This project focuses on analyzing coffee shop sales transactions to understand revenue performance, product popularity, store performance, and sales trends.

The goal is to apply data analytics techniques to raw sales data and turn the results into insights that can support business decision-making.

## Project Objectives

- Analyze overall sales and revenue.
- Identify top-performing products and product categories.
- Compare sales performance across store locations.
- Identify peak sales days and hours.
- Examine monthly sales trends.
- Develop data-driven business recommendations.

## Dataset

**Source:** [Coffee Shop Sales Dataset – Kaggle](https://www.kaggle.com/datasets/srisyra02/coffee-shop-sales-dataset/data)

The dataset contains coffee shop transaction records covering six months of sales activity.

The original CSV will be maintained locally during the initial inspection and analysis.
