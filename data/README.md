# Dataset

## Source

Coffee Shop Sales Dataset – Kaggle

https://www.kaggle.com/datasets/srisyra02/coffee-shop-sales-dataset/data

## Description

This dataset contains coffee shop sales transaction records covering six months of sales activity.

It includes information about transaction dates and times, product quantities, store locations, product categories, and unit prices.

## Data Usage

The original CSV is maintained locally during the initial inspection and analysis.

Dataset characteristics, data quality issues, and limitations will be documented as the project progresses.
